## ⚡ Your links. Your pages. Zero limits.

For years, creators and developers have been forced to choose between two extremes: overly simplistic link-in-bio directories with zero design freedom, or heavy, complex enterprise website builders. **C.L.A.W.S.** was built to shatter that false dichotomy. 

We combine a lightning-fast data layer with a robust visual architecture, allowing you to start simple with your daily links and effortlessly scale into a fully customized web presence without changing tools.

---

## Core Modes

*   **Mode 01 / Simple Mode:** Lightning-fast link and bio management. Drop your social profiles, organize content streams, and instantly sync changes directly to your live tree without layout friction.
*   **Mode 02 / Advanced Canvas:** Total structural freedom. Outgrew standard link trees? Flip into Advanced Mode powered by Craft.js to drag-and-drop modular blocks, nest multi-column layouts, and customize properties down to the finest detail.

---

## Our Tech Stack

Our application is built using modern, high-performance tooling focused on speed, security, and developer experience:

*   **Frontend & Routing:** Next.js (App Router) with built-in XSS sanitization for dynamic routes.
*   **Styling & UI:** Tailwind CSS paired with fluid `motion` animations.
*   **Development Environment:** Arch Linux backend managed via robust Git workflows.
